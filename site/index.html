    Run it

    Two modes. Offline replay rebuilds every number and this page from committed data: no keys, no network. Fresh research needs a Claude Code session: Python emits a task file, a subagent answers it, Python validates it. The agent does not run on its own outside Claude Code.

    Offline replay (reviewer)

    pip install -e .
python -m appresearch replay
# -> data/accuracy.json, data/analysis.json, site/index.html
python -m pytest -q   # rule checks

    Fresh research for one app

    # needs COMPOSIO_API_KEY in .env + Claude Code
python -m appresearch queries --app "Notion"
# in Claude Code: run WebSearch per query, then
python -m appresearch record-search "<query>" URL...
python -m appresearch research --app "Notion" --stage pass1
# subagent answers cache/llm/tasks/pass1/notion.md
#   (instructions: prompts/subagent_pass1.md)
python -m appresearch research --app "Notion" --ingest-only
